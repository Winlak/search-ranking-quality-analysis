# Данные

`src/pipeline.py` с фиксированным seed создаёт три файла в `data/generated/`:

- `ranking_rows.csv` — позиции документов baseline и candidate;
- `query_metrics.csv` — метрики на уровне запроса.
- `relevance_judgments.csv` — уникальные пары query_id/doc_id с оценкой 0/1/2, общие для обоих вариантов.

В каждом запросе ровно 10 документов. Candidate меняет только их порядок: оценки релевантности не меняются, новые документы не добавляются. Дубли документов, неполный пул и расхождения в оценках останавливают расчёт. Генератор использует оценки, чтобы создать учебную перестановку: это не модель, обученная без доступа к целевой разметке.

Данные синтетические, не содержат PII и не относятся к реальному поисковому сервису.
